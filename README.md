# Regra de Desconto da Assistência Médica

O desconto da assistência médica dos colaboradores é calculado com base na faixa salarial, seguindo as regras abaixo:

* **Isento:** salário de até **R$ 2.000,00** → desconto de **0%**
* **Mínimo:** salário acima de **R$ 2.000,00** até **R$ 4.000,00** → desconto de **2%**
* **Médio:** salário acima de **R$ 4.000,00** → desconto de **4%**
* **Máximo:** caso o valor do desconto ultrapasse **R$ 400,00**, será aplicado o limite máximo de **R$ 400,00**
